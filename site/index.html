Batch tools.
11—14 / FOLDER SCALE / BETA
These four Python tools recursively process WAV folders and asset trees. They are report-first and preserve source files. Optional transforms always target a separate output tree.
BETA / ONSETPACK
Put every transient on the same clock.
Locate first transients and create copies with consistent configurable pre-roll.
python onsetpack.py ./samples --preroll-ms 12 --output-dir ./samples-onset
Spec and limits ↗
BETA / PHASEBATCH
Check an entire multi-mic set.
Measure integer-sample delay and polarity against one reference and optionally write corrected copies.
python phasebatch.py ./mics --reference kick-in.wav --correct --output-dir ./aligned
Spec and limits ↗
BETA / PACKDELTA
Diff audio packs by sound data.
Compare two asset trees by decoded content including renames and duplicate families.
python packdelta.py ./pack-v1 ./pack-v2 --output pack-delta.json
Spec and limits ↗
BETA / EDGEGUARD
Find bad sample boundaries in bulk.
Audit start/end click risk and optionally write short-fade repaired copies.
python edgeguard.py ./oneshots --repair --fade-ms 4 --output-dir ./edge-fixed
Spec and limits ↗


Shell-native QC.
15—21 / BASH + POWERSHELL / BETA
Seven matched Bash and PowerShell tools orchestrate FFmpeg/FFprobe directly. They do not invoke the Python/JavaScript engines. Source audio is read-only, JSON/text reporting is normalized, and findings are review evidence rather than automatic fault claims.
STEREO / PHASE
stereotruth
Find likely dual-mono, sustained negative correlation and channel-balance candidates.
Internals and flags ↗
LOUDNESS / TIMELINE
loudwalk
Convert EBU R128 output into a short-term LUFS timeline with jump and deviation candidates.
Internals and flags ↗
FORMAT / METADATA
formattruth
Normalize codec, container, sample format and stream facts and flag inconsistencies.
Internals and flags ↗
BATCH / CONTRACT
albumcontract
Infer or enforce common sample rate, channel count and sample format across a delivery folder.
Internals and flags ↗
PHASE / TIMESTAMPS
phasewatch
Preserve a time-coded correlation ledger and surface negative regions or sharp changes.

BATCH / SILENCE
batchsilence
Measure leading/trailing silence across an export set and enforce optional timing limits.

Review codec/container/bitrate/encoder characteristics without claiming to prove transcode history.

Install FFmpeg and run the shell tools
Ubuntu/Debian: sudo apt update && sudo apt install ffmpeg. Windows: install FFmpeg and put ffmpeg.exe/ffprobe.exe on PATH.
bash bash/stereotruth.sh mix.wav --json
./powershell/stereotruth.ps1 mix.wav -Json
Exit codes: 0 clean completion, 1 review findings, 2 argument/dependency/input/analysis/report failure.
