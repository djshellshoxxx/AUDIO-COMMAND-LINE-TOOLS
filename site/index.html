Bash pipeline tools
06 TOOLS / BETA
Native Bash 4.4+ tools using FFmpeg, FFprobe, awk and standard Unix utilities. They do not call the Python or JavaScript engines. Text, TSV and JSONL output make the findings easy to feed into awk, sort, grep, xargs or optional jq. Research did not identify a well-established standalone command with the same narrow workflow for each composed analyzer; this is not a claim that no comparable implementation exists.


BETA
edgeguard
Flags hard starts/ends and possible truncated render boundaries from boundary energy and fade evidence.
Bash · FFmpeg · FFprobe · awk
bash bash/edgeguard.sh render.wav --format jsonl
find renders -name '*.wav' -print0 | xargs -0 -n1 bash bash/edgeguard.sh --format tsv --no-header
Events: possible_truncated_start · possible_truncated_end · discontinuity
Spec / internalsbash/edgeguard.sh


BETA
subphase
Inspects stereo correlation and balance only below a selectable crossover frequency.
Bash · FFmpeg · FFprobe · awk
bash bash/subphase.sh mix.wav --crossover-hz 120 --format jsonl
bash bash/subphase.sh mix.wav --format tsv | awk -F '\t' '$0 ~ /negative_sub_correlation/'
Events: weak · negative · critical sub correlation · low-band imbalance
Spec / internalsbash/subphase.sh


BETA
banddrift
Finds sections whose relative spectral-band energy departs from the same file's median balance.
Bash · FFmpeg · FFprobe · awk
bash bash/banddrift.sh master.wav --format tsv
bash bash/banddrift.sh master.wav --format tsv | sort -t $'\t' -k3,3
Events: band_share_high · band_share_low · broad_tonal_shift
Spec / internalsbash/banddrift.sh


BETA
repeataudit
Detects exact repeated decoded PCM blocks for recorder-buffer repetition and accidental duplicate regions.
Bash · FFmpeg · FFprobe · SHA-256 utility
bash bash/repeataudit.sh capture.wav --format jsonl
bash bash/repeataudit.sh capture.wav --format jsonl | grep adjacent_exact_repeat
Events: adjacent_exact_repeat · nonadjacent_exact_repeat
Spec / internalsbash/repeataudit.sh


BETA
samplefreeze
Finds exact or near-flat PCM runs, including non-zero frozen samples that silence detection misses.
Bash · FFmpeg · FFprobe · awk
bash bash/samplefreeze.sh recording.wav --format tsv
bash bash/samplefreeze.sh recording.wav --format jsonl | grep sample_freeze
Events: exact_sample_freeze · near_sample_freeze · zero_flatline
Spec / internalsbash/samplefreeze.sh


BETA
transientledger
Builds a timeline of transient-density and crest-factor changes relative to the file itself.
Bash · FFmpeg · FFprobe · awk
bash bash/transientledger.sh drums.wav --format jsonl
bash bash/transientledger.sh drums.wav --format tsv | grep transient_density
Events: transient_density_low/high · crest_factor_low/high
Spec / internalsbash/transientledger.sh

Flags, outputs, and formats
The Bash family supports text, TSV and JSONL. Exit code 0 means clean analysis, 1 means review events, and 2 means an input/dependency/analysis/output error. Inputs are never modified.
The original browser/Python/JavaScript tools retain their existing JSON report behavior and optional WAV export features.
These are narrow workflow combinations built after reviewing existing utilities. Related tools exist; this collection does not claim exclusive inventions. Read the research comparisons.
