Flags, outputs, and formats
Use --help to see each tool's flags. Reports are printed as JSON. Use --output report.json to write a report. Existing outputs require --overwrite. Source paths are always protected.
Tailbudget, Monoledger, DCjourney, Gainbudget, and Renderdelta support --audio-out result.wav. Exports are 16-bit PCM WAV without original metadata or dithering. Above-full-scale audio is refused. Gainbudget also enforces your requested ceiling when exporting.
Exit codes: 0 analysis finished; 1 stem contract failed; 2 invalid input, options, or I/O. Other tools report measurements for you to review.
These are narrow workflow combinations built after reviewing existing utilities. Related tools exist; this collection does not claim exclusive inventions. Read the research comparisons.
