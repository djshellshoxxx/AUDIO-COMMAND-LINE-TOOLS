Batch tools.
11—14 / FOLDER SCALE / BETA
These four Python tools recursively process WAV folders and asset trees. They are report-first and preserve source files. Optional transforms always target a separate output tree. They are featured here rather than executed in the browser because large recursive directory access varies by browser and operating system.


BETA / ONSETPACK
Put every transient on the same clock.
Scan one-shot and sample folders, locate the first threshold-crossing transient, and create copies with a consistent configurable pre-roll.
python onsetpack.py ./samples --threshold-db -24 --preroll-ms 12 --output-dir ./samples-onset
Spec and limits ↗


BETA / PHASEBATCH
Check an entire multi-mic set.
Measure integer-sample delay and polarity against one reference file. Optionally write aligned and polarity-corrected copies without touching sources.
python phasebatch.py ./mics --reference kick-in.wav --max-shift-ms 8 --correct --output-dir ./aligned
Spec and limits ↗


BETA / PACKDELTA
Diff audio packs by sound data.
Compare two asset trees by decoded content and separate unchanged, modified, added, removed, renamed, and duplicate-family files.
python packdelta.py ./pack-v1 ./pack-v2 --output pack-delta.json
Spec and limits ↗


BETA / EDGEGUARD
Find bad sample boundaries in bulk.
Audit start/end peak and slope risk across a sample tree. Optionally write short-fade repaired copies only for flagged files.
python edgeguard.py ./oneshots --repair --fade-ms 4 --output-dir ./edge-fixed

Flags, outputs, and formats
Use --help to see each tool's flags. Reports are JSON; batch tools can also emit CSV for row-oriented reports. Existing generated outputs require --overwrite. Source paths are protected and batch audio output trees may not be nested inside their source tree.
The original tools retain their documented WAV and measurement limits. Batch tools accept uncompressed PCM WAV 8/16/24/32-bit and write transformed audio as 16-bit PCM.
These are narrow workflow combinations built after reviewing existing utilities. Related tools exist; this collection does not claim exclusive inventions. Read the research comparisons.
