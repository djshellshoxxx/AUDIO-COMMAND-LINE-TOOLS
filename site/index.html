Batch tools.
11—14 / FOLDER SCALE / BETA
These four Python tools recursively process WAV folders and asset trees. They are report-first and preserve source files. Optional transforms always target a separate output tree. They are featured here rather than executed in the browser because large recursive directory access varies by browser and operating system.


BETA / ONSETPACK
Put every transient on the same clock.
Scan one-shot and sample folders, locate the first threshold-crossing transient, and create copies with a consistent configurable pre-roll.
python onsetpack.py ./samples --threshold-db -24 --preroll-ms 12 --output-dir ./samples-onset
Spec and limits ↗


BETA / PHASEBATCH
Check an entire multi-mic set.
Measure integer-sample delay and polarity against one reference file. Optionally write aligned and polarity-corrected copies without touching sources.
python phasebatch.py ./mics --reference kick-in.wav --max-shift-ms 8 --correct --output-dir ./aligned
Spec and limits ↗


BETA / PACKDELTA
Diff audio packs by sound data.
Compare two asset trees by decoded content and separate unchanged, modified, added, removed, renamed, and duplicate-family files.
python packdelta.py ./pack-v1 ./pack-v2 --output pack-delta.json
Spec and limits ↗


BETA / EDGEGUARD
Find bad sample boundaries in bulk.
Audit start/end peak and slope risk across a sample tree. Optionally write short-fade repaired copies only for flagged files.
python edgeguard.py ./oneshots --repair --fade-ms 4 --output-dir ./edge-fixed

Bash pipeline tools.
15—20 / UNIX PIPELINES / BETA
Six native Bash 4.4+ analyzers using FFmpeg, FFprobe, awk, and standard Unix utilities. They do not invoke the repository's Python or JavaScript engines. Text, TSV, and JSONL outputs are intended for composition with find, xargs, awk, grep, sort, and optional jq. Research did not identify a well-established standalone command with the same narrow end-to-end workflow for each tool; this is not a claim that no comparable implementation exists.


BETA / BASH / EDGEGUARD
Review suspicious file boundaries.
Combines boundary RMS, endpoint discontinuity, and short-window fade evidence to flag possible truncated starts or ends without altering source audio.
bash bash/edgeguard.sh render.wav --format jsonl
find renders -name '*.wav' -print0 | xargs -0 -n1 bash bash/edgeguard.sh --format tsv --no-header
Spec / internals ↗ bash/edgeguard.sh ↗


BETA / BASH / SUBPHASE
Inspect only the bass stereo relationship.
Low-passes both channels at the same crossover and reports sustained weak, negative, or critical low-band correlation plus balance issues.
bash bash/subphase.sh mix.wav --crossover-hz 120 --format tsv
bash bash/subphase.sh mix.wav --format tsv | awk -F '\t' '$0 ~ /negative_sub_correlation/'
Spec / internals ↗ bash/subphase.sh ↗


BETA / BASH / BANDDRIFT
Locate tonal-balance regime changes.
Measures configurable non-overlapping bands by window and reports runs whose relative energy share departs from the file's own median behavior.
bash bash/banddrift.sh master.wav --window-ms 500 --format jsonl
bash bash/banddrift.sh master.wav --format tsv | sort -t $'\t' -k3,3
Spec / internals ↗ bash/banddrift.sh ↗


BETA / BASH / REPEATAUDIT
Find exact decoded block repetition.
Groups SHA-256 block and sequence candidates, then byte-verifies them before reporting adjacent or non-adjacent repeated decoded PCM regions.
bash bash/repeataudit.sh capture.wav --block-ms 100 --format jsonl
bash bash/repeataudit.sh capture.wav --format jsonl | grep exact_repeat
Spec / internals ↗ bash/repeataudit.sh ↗


BETA / BASH / SAMPLEFREEZE
Find frozen sample values.
Detects exact or near-flat PCM runs at any level, including non-zero frozen values and overlapping multichannel freezes that silence detection misses.
bash bash/samplefreeze.sh recording.wav --min-run-ms 20 --format tsv
bash bash/samplefreeze.sh recording.wav --format jsonl | grep sample_freeze

BETA / BASH / TRANSIENTLEDGER
Map transient character over time.
Builds an energy envelope, counts separated transient rises, measures crest factor, and reports density/crest regimes relative to active-window medians.
bash bash/transientledger.sh drums.wav --window-ms 1000 --format jsonl
bash bash/transientledger.sh drums.wav --format tsv | grep transient_density

WinAudioForensics.
21 / WINDOWS / POWERSHELL / BETA
A read-only Windows audio-state recorder for problems that are difficult to explain after the fact: unexpected default-device changes, USB/interface disappearances, driver swaps, endpoint state changes, and stopped Windows Audio services. Capture while working, capture after the symptom, then compare the evidence.
POWERSHELL 7+ / WINDOWS NATIVE
Find what changed.
Queries services, CIM/PnP, signed drivers, MMDevices endpoint metadata, documented Core Audio default roles, and optional recent event-log evidence. No Python runtime or external PowerShell module is required.
.\WinAudioForensics.ps1 snapshot -Output working.json
.\WinAudioForensics.ps1 snapshot -IncludeEvents -Output broken.json
.\WinAudioForensics.ps1 diff -Before working.json -After broken.json
Usage guide ↗ Spec + pseudocode ↗
SNAPSHOT / DIFF / DOCTOR / WATCH
Evidence instead of screenshots.
Deterministic diffs report device, driver, endpoint, default-role, and service changes. Doctor rules flag evidence without treating correlation as proof of cause. Watch mode writes state only when meaningful audio configuration changes.
.\WinAudioForensics.ps1 doctor -Snapshot broken.json -Diff change.json
.\WinAudioForensics.ps1 watch -IntervalSeconds 5

Flags, outputs, and formats
Use --help to see each Python/JavaScript/Bash tool's flags. The Bash family produces text, TSV, or JSONL and returns 1 when review findings are present. Batch tools can also emit CSV for row-oriented reports. Existing generated outputs require --overwrite. Source paths are protected and batch audio output trees may not be nested inside their source tree.
The original tools retain their documented WAV and measurement limits. Batch tools accept uncompressed PCM WAV 8/16/24/32-bit and write transformed audio as 16-bit PCM. Bash analyzers accept formats FFmpeg can decode and operate on temporary canonical PCM. WinAudioForensics is a separate Windows-native read-only evidence collector and does not alter audio settings.
These are focused workflow combinations built after reviewing existing utilities. Related tools exist; this collection does not claim exclusive inventions. Read the audio-tool research.
