Batch tools.
11—14 / FOLDER SCALE / BETA
These four Python tools recursively process WAV folders and asset trees. They are report-first and preserve source files. Optional transforms always target a separate output tree.
BETA / ONSETPACK
Put every transient on the same clock.
Scan one-shot and sample folders, locate the first threshold-crossing transient, and create copies with consistent pre-roll.
python onsetpack.py ./samples --preroll-ms 12 --output-dir ./samples-onset
Spec and limits ↗
BETA / PHASEBATCH
Check an entire multi-mic set.
Measure integer-sample delay and polarity against one reference file and optionally write corrected copies.
python phasebatch.py ./mics --reference kick-in.wav --correct --output-dir ./aligned
Spec and limits ↗
BETA / PACKDELTA
Diff audio packs by sound data.
Compare two asset trees by decoded content and separate unchanged, modified, added, removed, renamed and duplicate-family files.
python packdelta.py ./pack-v1 ./pack-v2 --output pack-delta.json
Spec and limits ↗
BETA / EDGEGUARD
Find bad sample boundaries in bulk.
Audit start/end peak and slope risk across a sample tree and optionally write repaired copies.
python edgeguard.py ./oneshots --repair --fade-ms 4 --output-dir ./edge-fixed

WinAudioForensics.
15 / WINDOWS / POWERSHELL / BETA
A read-only Windows audio-state recorder for problems that are difficult to explain after the fact: unexpected default-device changes, USB/interface disappearances, driver swaps, endpoint state changes, and stopped Windows Audio services.
POWERSHELL 7+ / WINDOWS NATIVE
Find what changed.
Queries services, CIM/PnP, signed drivers, MMDevices endpoint metadata, documented Core Audio default roles and optional recent event-log evidence.
.\WinAudioForensics.ps1 snapshot -Output working.json
.\WinAudioForensics.ps1 snapshot -IncludeEvents -Output broken.json
.\WinAudioForensics.ps1 diff -Before working.json -After broken.json
Usage guide ↗ Spec + pseudocode ↗
SNAPSHOT / DIFF / DOCTOR / WATCH
Evidence instead of screenshots.
Deterministic diffs report device, driver, endpoint, default-role and service changes. Doctor rules flag evidence without treating correlation as proof of cause.
.\WinAudioForensics.ps1 doctor -Snapshot broken.json -Diff change.json
.\WinAudioForensics.ps1 watch -IntervalSeconds 5

Shell-native QC.
16—22 / BASH + POWERSHELL / BETA
Seven matched Bash and PowerShell tools orchestrate FFmpeg/FFprobe directly. They do not invoke the Python or JavaScript engines. Source audio is read-only, output can be machine-readable JSON, and findings are review evidence rather than automatic fault claims.
STEREO / PHASE
stereotruth
Find likely dual-mono, sustained negative correlation and channel-balance candidates.
bash bash/stereotruth.sh mix.wav --json
./powershell/stereotruth.ps1 mix.wav -Json

Install FFmpeg and understand shell-tool exits
Ubuntu/Debian: sudo apt update && sudo apt install ffmpeg. Windows: install FFmpeg and put ffmpeg.exe/ffprobe.exe on PATH; winget install Gyan.FFmpeg is one option.
Exit codes: 0 completed with no policy findings, 1 completed with review findings, 2 argument/dependency/input/analysis/report failure.
