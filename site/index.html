Shell-native QC.
07 / BASH + POWERSHELL / BETA
These are independent shell tools, not wrappers around the Python engine. FFmpeg and FFprobe perform decoding and measurement; the Bash and PowerShell implementations handle discovery, aggregation, policy thresholds, JSON/text reports and exit codes. They accept formats supported by your FFmpeg build and never modify source audio.

Install FFmpeg and understand shell-tool exits
Ubuntu/Debian: sudo apt update && sudo apt install ffmpeg. Windows: install a current FFmpeg build and place ffmpeg.exe and ffprobe.exe on PATH; winget install Gyan.FFmpeg is one option.
Shell-native exit codes: 0 completed with no policy findings, 1 completed with review findings, 2 invalid arguments, missing dependency, unreadable input, analysis failure or report-write failure. Findings are evidence to inspect, not automatic claims of corruption or mastering errors.

Flags, outputs, and formats
Use --help to see each original CLI tool's flags. Reports are printed as JSON. Use --output report.json to write a report. Existing outputs require --overwrite. Source paths are always protected.
Tailbudget, Monoledger, DCjourney, Gainbudget, and Renderdelta support --audio-out result.wav. Exports are 16-bit PCM WAV without original metadata or dithering.
The shell-native tools use FFmpeg/FFprobe and have their own 0/1/2 QC exit contract described above. Related tools and primitives already exist; this collection does not claim exclusive inventions.
