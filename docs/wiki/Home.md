# Audio Command Line Tools Wiki

Twenty-two beta-stage audio utilities from Circuit Drift Labs: WAV analysis and QC tools in Python,
Node and the browser, Bash and PowerShell FFmpeg/FFprobe workflows, and the WinAudioForensics capture tool.

**All tools are beta.** Keep source audio backed up and review every report before acting on it.
